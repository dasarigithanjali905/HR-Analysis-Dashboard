# HR Analytics Dashboard – Power BI

## 📊 Project Overview

This project is an **HR Analytics Dashboard built using Microsoft Power BI**. It provides interactive insights into employee demographics, salary, experience, hiring trends, seniority, and salary differences.

The dashboard helps HR teams understand workforce trends and analyze employee-related metrics through interactive visualizations and filters.

## 🎯 Objectives

* Analyze employee demographics and workforce distribution.
* Understand salary trends across different employee groups.
* Analyze employee experience and seniority levels.
* Track employee joining trends over time.
* Identify salary differences by gender and county.
* Provide interactive filtering for HR analysis.

## 📌 Key KPIs

The dashboard includes the following key metrics:

* **Total Employees**
* **Average Salary**
* **Salary Gap**
* **Total Hike**
* **Employees Joined After 2015**
* **Average Age in Company**
* **Last Hike Percentage**

## 🔎 Interactive Filters

Users can filter the dashboard using:

* County
* Salary Band
* Age Category
* Experience Band

## 📈 Dashboard Visualizations

The report contains several interactive visualizations, including:

* Employee Joining Trend by Year
* Employee Joining Trend by Month
* Total Salary by Gender
* Average Salary by Experience Band
* Employee Distribution by Weight Category
* Salary Gap by Gender
* Employees by Seniority Level
* Average Salary by County
* Employee Distribution by County using a Map
